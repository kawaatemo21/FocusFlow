# FocusFlow – Your Personal Task Manager

FocusFlow is a simple and modern task management application built with React. It helps users organize their daily tasks, track their progress, and stay focused.

## Features

- **Add Tasks:** Create tasks with a title, description, and priority.
- **Manage Tasks:** Mark tasks as completed, reopen them, or delete them.
- **Priority Levels:** Choose between High, Medium, and Low.
- **Filter Tasks:** Display all tasks, only open tasks, or completed tasks.
- **Search Tasks:** Find tasks quickly using the search bar.
- **Dashboard:** View the total number of tasks, open tasks, and completed tasks.
- **Local Storage:** Automatically save tasks so they remain available after refreshing the page.
- **Responsive Design:** Use the application on desktop and mobile devices.

## Technologies Used

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kawaatemo21/FocusFlow.git
```

### 2. Open the project folder

```bash
cd FocusFlow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use FocusFlow.
